# 물 받아라! — 게임 기획서 v0.1

작성일: 2026-09-20 · 상태: 초기 밸런스 기반 로컬 2인 MVP 구현 완료

구현 메모: 본 문서의 수치와 판정 규칙을 그대로 적용했다. 휴대폰 세로 화면은 터치 버튼의 최소 56px 크기를 확보하도록 조작 패널을 위아래로 배치하며 가로 사용 안내를 제공한다. 이름·컵 선택은 가능한 경우 브라우저 로컬 저장소에 보관한다. 사운드는 후속 범위다.

## 0. v0.2 변경 (두 번째 손그림 메모 반영)

- **배경 선택**: 시작 화면에서 주방·화장실·우주 배경을 고른다.
- **비밀 레몬**: 라운드마다 한 번(12~36초 사이 무작위), 레몬 조각 5개가 물줄기와 다른 레인으로 빠르게(0.38초) 떨어진다. 점수는 없고 개수만 센다. 안내 문구 없이 숨겨 둔다.
- **게임 끝 장면**: 라운드가 끝나면 물 받은 친구가 컵을 마신다(“아~”). 이어 반응한다. 우선순위는 레몬 3개 이상 → 하트 눈, 똥물을 한 번이라도 받음 → 우웩, 그 외 → 엄지 척. 최종 결과 카드에도 각자의 반응을 보여 준다.
- **자리 고정 조작**: 키와 조작 패널은 역할이 아니라 자리에 붙는다. 친구 1(왼쪽) A/S/D·똥물 W, 친구 2(오른쪽) ←/↓/→·똥물 ↑. Space는 현재 방해하는 쪽의 똥물. 역할이 바뀌면 같은 자리의 패널이 물 받기↔방해하기로 바뀐다.
- **똥물 예고 단축**: 0.7초 → 0.35초. 버튼을 누른 뒤 똥물이 나오기 시작하기까지 절반으로 줄었다(컵 도착까지 약 1.35초 → 1.0초).

## 0-1. v0.3 변경

- **레몬 엔딩 조건**: 레몬을 1개라도 받으면 레몬(하트 눈) 엔딩. 우선순위는 그대로 레몬 → 똥물 → 깨끗함.
- **레몬 출현**: 라운드당 두 번(10~20초, 26~36초 사이 무작위). 한 번에 3조각이 0.35초 간격으로 천천히 나오고, 0.48초 만에 떨어져 물(0.65초)보다 빠르다. 레인은 매번 물줄기와 다른 곳.
- **물슐랭 3스타**: 마지막 라운드 결과에서 캐릭터와 같은 모습에 수염이 긴 심사위원 아저씨가 이긴 친구의 컵(동점이면 마지막 컵)을 마시고 3스타 배지를 준다.
- **우주 외계인**: 우주 배경이면 외계인이 “여기가 물맛이 좋다고 유명한 덴가? 삐빅_” → (꿀꺽) → 그 컵에 똥물이 없었으면 “그냥 신선한 물맛이군_”, 있었으면 “삐빅! 삐빅! 이건… 똥물 맛이다! 퉤퉤_”.

## 1. 한 문장 소개

컵을 든 말랑한 친구와 장난꾸러기 물줄기 조종사가 펼치는 2인 대결. 깨끗한 물은 따라가서 받고, 똥물은 예고를 보고 피한다!

## 2. 원본과 결정 상태

### 사용자 요청으로 확정된 내용

- 웹앱에서 두 사람이 **한 기기에서 화면과 조작을 나눠** 플레이한다.
- **메모의 둥글고 귀여운 손그림 스타일**을 유지한다. 두 항목 모두 사용자가 추가 답변으로 확정했다.
- 한 사람은 물을 받는다. 다른 사람은 물줄기를 움직이고 가끔 똥물을 틀어 물을 못 받게 한다.
- 캐릭터는 원본 손그림의 동그란 머리, 작은 몸, 짧은 팔다리, `^ ^` 눈과 `w` 모양 입을 따른다.
- 이번 산출물은 Markdown 기획 문서와 핵심 에셋이다. 본격적인 게임 개발은 다음 세션이다.

### 메모에서 읽어 반영한 내용

- 좌·가운데·우 버튼, 물 받기/방해하기 영역, 컵과 위에서 내려오는 물줄기.
- 컵 색을 고르는 아이디어(노랑·빨강·하늘색으로 읽음)는 준비 화면의 선택 기능으로 반영.
- 일부 작은 글씨는 명확하지 않다. 똥물을 피하는 상세 규칙과 결과 연출은 아래 제안으로 보완했으며 원문을 그대로 옮긴 것이 아니다.

### 구성 기본안 — 접속과 미술은 확정, 나머지는 제안

| 항목 | 기본안 | 이유 |
|---|---|---|
| 접속 (확정) | 한 기기에서 함께 플레이 | 메모의 두 조작 영역을 살리고 설치·방 입장 없이 시작 |
| 미술 (확정) | 따뜻한 종이색과 손그림 선의 귀여운 2D | 원본 캐릭터의 인상 유지 |
| 이동 | 3개 레인: 왼쪽·가운데·오른쪽 | 작은 화면에서 즉시 이해하고 조작 |
| 승패 | 역할 교대 2라운드, 받은 물의 양 비교 | 양쪽 모두 동일한 역할 기회 |
| 라운드 | 45초, 동일 점수면 공동 우승 | 한 판 약 2분 이내 |
| 똥물 효과 | 받으면 물 100mL 감소 | 역전 가능하되 처음부터 다시 시작하지 않음 |

## 3. 핵심 플레이 흐름

1. 두 플레이어가 이름(기본 ‘친구 1’, ‘친구 2’)과 컵 색을 정하고 역할을 확인한다.
2. ‘시작’ 후 3초 카운트다운. 1라운드는 친구 1이 물 받기, 친구 2가 방해하기.
3. 받는 사람은 현재 물줄기 아래로 컵을 옮긴다. 방해하는 사람은 물줄기를 옮겨 따돌린다.
4. 방해하는 사람이 똥물 버튼을 누르면 0.35초 동안 경고한다. 이어 0.6초 분량의 똥물이 발사된다. 받는 사람은 똥물이 도착하기 전에 다른 레인으로 피한다.
5. 45초 종료 시 즉시 점수를 확정한다. 화면 안에 남은 물은 더 계산하지 않는다.
6. 역할을 바꾸고 양쪽이 준비를 누르면 같은 조건으로 2라운드 진행.
7. 각자 물 받기 역할에서 얻은 최종 물의 양을 비교한다. 더 많이 받은 사람이 승리. 같으면 공동 우승.

## 4. 조작

| 역할 | 터치 | 키보드 |
|---|---|---|
| 물 받기 | 왼쪽 조작 패널의 좌·중앙·우 버튼 | A / S / D |
| 방해하기 | 오른쪽 패널의 좌·중앙·우 버튼 | ← / ↓ / → |
| 똥물 | 오른쪽 패널의 별도 ‘똥물!’ 버튼 | Space |
| 일시정지 | 상단 일시정지 버튼 | Escape |

버튼은 방향으로 계속 움직이는 조이스틱이 아니라 **해당 레인으로 이동하는 선택 버튼**이다. 꾹 눌러도 한 번의 선택으로 처리한다. 두 사람의 동시 터치를 독립 처리한다. 키보드 조작도 역할과 함께 바뀌며, 교대 화면에 크게 안내한다.

한 기기 기본안: 태블릿 가로 화면과 데스크톱을 우선한다. 휴대폰 세로에서는 가로 사용 안내를 제공하되 메뉴 접근은 유지한다. 좌우 패널은 같은 경기장을 조작한다. 각각 다른 경기를 보여주는 분할 화면이 아니다.

온라인 접속은 이번 범위에서 제외한다. 두 사람은 하나의 경기장과 좌우의 독립 조작 패널을 공유한다.

## 5. 물과 이동의 판정

- 경기장은 3레인. 컵과 물줄기는 가운데에서 시작한다. 카운트다운 중에는 입력과 발사를 막는다.
- 받는 사람은 선택한 레인으로 0.14초 동안 이동한다. 충돌 판정용 레인은 이동 완료 때 변경한다. 이동 중에는 이전 레인으로 판정한다. 이동 도중 들어온 입력은 마지막 하나만 대기시킨다.
- 물줄기 이동은 즉시 다음 발사 위치에 반영한다. 변경 후 0.45초 동안 다시 옮길 수 없다. 잠긴 동안의 변경 입력은 무시하고 버튼에 남은 시간을 표시한다.
- 물은 0.1초마다 한 묶음씩 발사된다. 묶음마다 발사 레인·종류·도착 시각이 고정된다. 이미 떨어지는 물은 수도꼭지를 따라 순간 이동하지 않는다.
- 비행 시간은 0.65초. 도착 순간 컵 판정 레인과 같은 깨끗한 물 묶음은 +10mL, 다른 레인이면 빗나간다.
- 점수는 0 이상, 상한 없음. 컵은 250mL마다 채워졌다 비워지는 시각 효과를 사용하고 누적량은 상단에 따로 표시한다. 컵 비움 연출 때문에 판정이 중단되지는 않는다.
- 정수 mL로 저장한다. 표시용 게이지 애니메이션이 실제 점수를 결정하지 않는다.

## 6. 똥물 규칙

상태 순서: `사용 가능 → 예고(0.35초) → 발사(0.6초) → 남은 재사용 대기 → 사용 가능`.

- 라운드당 최대 4회. 라운드 시작 6초 후 첫 사용 가능.
- 한 번 누르면 1회 소모하고, 누른 순간부터 8초 재사용 대기. 누르기 전 남은 횟수와 대기를 모두 검사한다.
- 예고 동안 물은 계속 깨끗하다. 수도꼭지에 경고 모양과 ‘똥물 준비!’ 문구를 표시한다.
- 사용을 누른 순간부터 똥물 발사 종료까지 **수도꼭지 레인을 잠근다**. 받는 사람이 예고를 보고 피할 시간을 보장한다.
- 발사 중에는 깨끗한 물 대신 갈색 물이 나온다. 각 묶음에 같은 `burstId`를 부여한다.
- 같은 똥물 사용에서 여러 묶음을 받아도 감점은 한 번만 적용한다. `max(0, 점수 - 100mL)`로 계산한다.
- 똥물을 맞아도 이동은 가능하다. 0.5초 갈색 튐·흔들기 효과만 보여 준다(찡그림은 후속 표정 에셋 추가 시 적용). 다른 사용의 똥물은 별도로 판정한다.
- 마지막 똥물이 도착하기까지 위험 표시를 유지한다. 발사 종료 후에는 수도꼭지를 다시 이동할 수 있다.
- 색 외에도 방울 모양·거품·경고 아이콘을 달리한다. 사실적인 배설물 표현은 쓰지 않는다.

## 7. 초기 밸런스 표

모든 수치는 플레이 테스트 전 제안값이다. 한 곳의 설정 파일로 관리한다.

| 설정 | 초기값 |
|---|---:|
| 라운드 시간 | 45,000ms |
| 카운트다운 | 3,000ms |
| 컵 이동 시간 | 140ms |
| 물줄기 이동 제한 | 450ms |
| 물 묶음 간격 / 양 | 100ms / 10mL |
| 낙하 시간 | 650ms |
| 컵 시각적 용량 | 250mL |
| 똥물 첫 사용 대기 | 6,000ms |
| 똥물 예고 / 발사 | 350ms / 600ms |
| 똥물 재사용 대기 / 횟수 | 8,000ms / 4회 |
| 똥물 감점 | 사용당 100mL |

튜닝 우선순위: (1) 경고를 보고 피할 수 있는가 (2) 컵이 물줄기를 따라잡는가 (3) 똥물을 모두 피하더라도 방해 역할이 재미있는가. 관찰 후 숫자만 조정한다. 물을 거의 못 받으면 물줄기 이동 제한을 늘리고, 항상 받으면 줄인다.

## 8. 화면 구성과 문구

### 준비 화면

제목 ‘물 받아라!’ · 설명 ‘깨끗한 물은 받고, 똥물은 피하자!’ · 두 플레이어 이름과 컵 색 · 역할 설명 · 시작 버튼. 이름 입력은 생략 가능하다.

### 경기 화면

```text
┌──────────────────────────────────────────────┐
│ 1 / 2 라운드     00:45     받은 물 320mL   Ⅱ │
│                [수도꼭지]                   │
│   왼쪽            가운데             오른쪽 │
│                     물                      │
│              [컵] [동그란 친구]              │
├─────────────────────┬────────────────────────┤
│ 물 받기 · 친구 1    │ 방해하기 · 친구 2      │
│  [좌] [중앙] [우]   │ [좌] [중앙] [우]       │
│  A     S     D      │  ←    ↓     → [똥물!]  │
└─────────────────────┴────────────────────────┘
```

컵의 중심이 레인의 중심이다. 캐릭터는 컵 오른쪽에서 손잡이를 잡는다. 인물 중심으로 충돌을 계산하지 않는다.

### 교대 및 결과

- 교대: ‘이번엔 역할 바꾸기!’ · 1라운드 기록 · 새 역할·키 안내 · 각자 ‘준비 완료’.
- 결과: 두 사람의 물 양을 같은 크기로 표시 · ‘친구 1 승리!’ 또는 ‘둘 다 최고! 공동 우승’ · 캐릭터 축하 동작 · ‘한 판 더’와 ‘처음으로’.
- 재경기는 시작 역할을 바꾸고 점수·입력·똥물 횟수를 모두 초기화한다.

## 9. 시각·소리·접근성

종이색 배경, 짙은 갈색 손그림 윤곽, 하늘색 물, 코코아색 똥물, 노랑·코랄·하늘색 컵. 캐릭터는 둥근 머리와 작은 몸의 비율을 유지한다. 역할은 색과 글자로 함께 표시한다.

버튼 최소 56 CSS px, 선택 표시와 눌림 표시를 구분한다. 숫자 타이머와 큰 mL 표시는 캐릭터보다 우선한다. 감소한 모션 설정에서는 흔들기와 큰 튐을 생략한다. 소리 없이도 예고·피격·종료를 이해할 수 있어야 한다.

소리 계획(이번 에셋 범위 밖): 짧은 ‘톡’ 선택음, 물방울 수집음, 똥물 예고음, 우승 징글. 음소거 버튼을 둔다. 자동 재생에 의존하지 않는다.

## 10. 범위

MVP: 준비 → 두 라운드 → 교대 → 결과, 로컬 2인 동시 입력, 세 레인, 물 수집, 똥물, 일시정지, 재시작, 컵 색, 에셋 적용.

후속: 각자 기기 온라인 모드, 추가 표정/프레임, 소리, 난이도, 더 많은 컵. 로그인·랭킹·상점·AI 상대는 초기 범위에 넣지 않는다.

- 다음 세션은 이 확정사항으로 바로 개발할 수 있다.
- 역할 교대 45초 × 2와 100mL 감점은 우선 플레이해 보고 조정할 제안값이다.
