# 핵심 에셋 가이드

## 제작 결과

손그림 캐릭터 PNG 1개와 독립 SVG 소품·효과·조작 아이콘 18개. 캐릭터는 내장 imagegen으로 원본 메모를 참고해 생성했고, 단순 도형인 컵·수도꼭지·물방울·UI는 직접 작성한 벡터다. 외부 폰트나 외부 이미지 다운로드는 사용하지 않았다.

`assets/preview.html`을 브라우저에서 열면 구성 예시와 전체 에셋을 확인할 수 있다. 실행 가능한 게임은 아니다. 모든 에셋 경로와 크기는 `assets/manifest.json`에 있다.

## 스타일 규칙

- 배경 `#fff8e8`, 윤곽 `#493c32`, 물 `#70cbe6`, 똥물 `#b58a60`.
- 컵 색: 노랑 `#f5ca62`, 코랄 `#f29b89`, 하늘 `#a3d9e8`.
- 인물은 큰 둥근 머리, 짧은 팔다리, `^ ^` 눈과 `w` 입. 신체를 사실적으로 만들지 않는다.
- PNG는 질감 있는 손그림, SVG는 둥근 선과 비대칭 곡선으로 연결한다. SVG는 배경이 투명하다.
- 깨끗한 방울과 똥물 방울은 색뿐 아니라 거품 점으로 구분한다. UI 경고에는 텍스트도 함께 둔다.

## 캐릭터와 컵 조합

캐릭터 PNG 원본 크기는 1238×1271. 왼쪽으로 뻗은 빈손에 별도 컵을 배치한다. 정규화한 시각 기준점: 발 아래 약 `(0.53, 0.91)`, 컵 손잡이와 만나는 왼손 약 `(0.19, 0.63)`. 기준점은 원본 여백을 포함하며 첫 게임 렌더에서 미세 조정한다.

컵 SVG는 128×144, 입구 중심 `(55,29)`, 손잡이 오른쪽 접점 약 `(123,74)`. 표시 크기가 바뀌면 두 기준점 모두 같은 배율로 변환한다. 컵을 먼저 그리고 캐릭터를 뒤에 그리면 손이 손잡이 위로 자연스럽게 겹친다. 컵 색은 플레이어에게 귀속되어 역할이 바뀌어도 유지된다.

컵과 캐릭터의 가로 간격을 고려해 오른쪽 레인에 여백을 둔다. 충돌은 이미지 픽셀이나 머리 위치 대신 논리 레인과 컵 입구를 사용한다.

## 컵 수위

`cup-water-fill.svg`는 약 60% 수위의 정적 예시다. 개발 시 전체 SVG를 세로로 찌그러뜨리는 대신 아래 내부 경로로 클립하고, 수위에 따라 물 사각형 높이를 바꾼다.

```text
컵 내부 clip path: M21 40 H89 L83 122 Q55 129 27 122 Z
수위 범위: y=122(비어 있음) … y=40(가득 참)
표시 비율: (누적 물 mL % 250) / 250
레이어 순서: 수위 → 컵 외곽 → 캐릭터 → 튐/텍스트
```

250mL를 넘는 순간 짧게 가득 찬 모습을 보여 주고 비우되 점수는 유지한다. 감점 시 현재 누적량 기준으로 수위를 다시 계산한다. 수위 표현은 피드백이고 총점의 기준은 상단 mL 숫자다.

## 애니메이션 적용 계획

현재 PNG는 정지 프레임 하나다. 다음 세션 MVP에서는 수집 때 1.04배 짧은 튕김, 이동 때 약한 기울기, 피격 때 갈색 splash와 흔들기, 우승 때 crown과 점프로 대응한다. 표정을 바꾼 PNG나 프레임 시트가 포함되어 있다고 가정하지 않는다. 피격 찡그림은 후속 표정 에셋을 만들 때 추가하고, 초기 구현은 효과로 대체한다.

물줄기는 장식이며 실제 물 묶음은 방울 에셋으로 그린다. 깨끗한 물과 똥물이 동시에 공중에 있을 수 있으므로 하나의 긴 줄 전체를 한꺼번에 갈색으로 바꾸지 않는다.

## 제작 출처와 재생성

- 캐릭터 입력: 저장소의 `IMG_5069.jpg`에 그린 인물. 원본 사진 전체를 게임 배경으로 사용하지 않았다.
- 방식: 내장 `image_gen` 도구, 참고 이미지 1장, 투명 PNG. 생성본을 저장소 `assets/characters/friend-idle.png`로 복사했다.
- 실제 사용한 전체 프롬프트: [character-prompt.txt](character-prompt.txt).
- 벡터 원본은 SVG 자체. 재생성 스크립트: `python3 scripts/build-vector-assets.py`. 이 명령은 해당 SVG 및 manifest를 덮어쓰므로 SVG를 직접 수정했다면 스크립트에도 반영한다. PNG는 변경하지 않는다.
- 이번 작업은 시각 에셋까지다. 사운드 파일, 별도 승리/피격 캐릭터 프레임, 실제 게임 구현은 포함하지 않는다.
