# MVP 검증 기록

검증일: 2026-09-20

## 자동 테스트

`npm test` — Node.js 내장 테스트 러너, 10개 통과.

- 첫 깨끗한 물 도착 750ms, 45초 이전 총 443묶음 / 4,430mL, 종료 후 추가 점수 없음.
- 컵 이동 완료와 도착의 동시각 순서, 이동 중 마지막 입력 보관.
- 수도꼭지 이동 제한, 잠금 중 입력 무시, 이미 발사된 묶음의 레인 유지.
- 똥물 첫 6초 제한, 700ms 예고, 600ms 발사 구간, 사용당 여섯 묶음·감점 한 번.
- 감점 후 점수 하한 0, 피한 똥물 감점 없음, 재사용 대기 및 4회 한도.
- 발사 시각 입력의 우선순위.
- 동일 입력 기록으로 60Hz / 120Hz / 1초 간격 프레임 진행 결과 일치.
- 역할별 점수 기록, 승자·공동 우승, 시작 역할 반전 및 재경기 초기화.
- EventTarget 기반 입력 테스트: 서로 다른 두 pointer ID, 키보드 양쪽 입력, 키 반복 억제, pointercancel, blur, visibilitychange, 비활성 버튼.

## 실제 Chrome 브라우저

- 기존 PNG/SVG 정상 로드, 준비 화면과 컵 색 선택.
- 3초 카운트다운, A와 왼쪽 방향키로 양쪽 레인 변경 확인.
- Space 사용 후 똥물 횟수 감소 및 위치 잠금 표시.
- Escape 정지, 시간·점수가 유지되는 것을 두 시점에서 확인한 후 계속하기.
- 첫 라운드 4,220mL로 종료 → 한 명만 준비해도 대기 → 두 번째 준비 시 역할 교대.
- 두 번째 라운드 4,430mL로 종료 → 친구 2 승리 및 양쪽 점수 표시.
- 한 판 더 → 친구 2가 먼저 물 받기, 0mL / 45초 / 똥물 4회로 초기화.
- 데스크톱, 1024×768 태블릿 가로, 390×844 휴대폰 세로 크기에서 확인.
- 휴대폰에서 가로 넘침 없음. 컵 선택 56×56px, 경기 레인 버튼 최소 79×66px 확인.
- 브라우저 오류·경고 로그 없음.

## 남은 실기기 검수

실제 태블릿의 두 손가락 동시 터치와 모바일 Safari는 이 환경에서 실행하지 않았다. 두 pointer 입력의 독립성은 자동 테스트로 확인했으며, 실제 터치 하드웨어에서 감도·손 배치·브라우저 제스처 간섭을 추가 확인할 수 있다. 자동 테스트는 실제 터치 기기 검증을 대체하지 않는다.

사운드 및 온라인 대전은 기획상 후속 범위다. 배포는 수행하지 않았다.
